Assinando o podcast com o Rhythmbox

O Rhythmbox é um software livre, reprodutor de áudio, que ajuda a organizar músicas digitais. 
Para assinar via RSS SoundCloud, através do Rhythmbox, é preciso ter a versão 3.2 ou superior. 

Outra opção é instalar um plugin, ajustando assim a compatibilidade. 

  • Acesse a documentação oficial - https://wiki.gnome.org/Apps/Rhythmbox
  • Repositório no Github - https://github.com/GNOME/rhythmbox
